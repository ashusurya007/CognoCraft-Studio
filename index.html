Rise 360, AI Prompting & SCORM 1.2/2004 Workflow

100% White-Labeled Output: Every exported HTML file and SCORM zip is completely unbranded so learners never see CognoCraft Studio watermarks or comments.
  1. Draft Rapidly with AI SME Prompts: Open any block in the Studio, click Copy SME Prompt, paste it alongside your SME notes into any LLM, and paste the resulting JSON back into Import AI JSON.
  2. SME Sign-Off Tables: Click SME Script (.doc) to download a Word-compatible review table with a dedicated redline column.
  3. Unlock Rise 360 Continue Blocks: Keep Rise 360 Continue Block Unlock checked so finishing the block fires postMessage({ type: 'complete' }, '*') automatically.
  4. No-Code HTML Editor & SCORM Player: Edit any HTML file visually in HTML Editor, or drop any SCORM 1.2/2004 .zip package into SCORM Player to verify manifest structure and live LMS API calls.
