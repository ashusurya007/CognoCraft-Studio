# CognoCraft-Studio
Pedagogy-first HTML5 &amp; SCORM 1.2 authoring studio for Instructional Designers. Build 16 white-labeled interactive learning blocks mapped to Bloom’s Taxonomy &amp; Gagné’s 9 Events, generate AI SME prompts, export Word redline tables, edit HTML visually without code, and unlock Articulate Rise 360 Continue blocks automatically.
